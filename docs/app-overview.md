# Обзор приложения

**Bitrix24 CRM Assistant** — локальный мост между Bitrix24 и Claude: чат с CRM, аналитика (read-only), протоколы встреч, плановые сводки и исходящие сообщения. Изменения в Bitrix24 только через **Safety Layer**: prepare → предпросмотр → подтверждение → commit.

Секреты и API-ключи в UI не хранятся. По умолчанию `APP_ACCESS_MODE=local_only`.

## Принципы

| Принцип | Суть |
|---------|------|
| Read свободно | Просмотр CRM, отчёты, контекст клиента — без подтверждения |
| Write только с confirm | Задачи, комментарии, отправка сообщений — сначала preview |
| Нет автозаписи | Webhook и расписания сами в CRM не пишут |
| Клиентский контекст | Чат может быть привязан к сделке / лиду / контакту / компании |

Подробнее: [action-safety.md](./action-safety.md), [client-context.md](./client-context.md).

## Работа

### Чат

Основной диалог с ассистентом: запросы к CRM, анализ, подготовка действий.

- слева — проекты, последние чаты, архив, поиск;
- привязка к CRM-сущности (карточка + обновление контекста);
- изменяющие действия показывают блок подтверждения (иногда с фразой).

### Проекты

Рабочие пространства: инструкции, файлы (md/txt в контекст), диалоги, связанные CRM-сущности, шаблон протокола встреч.

Проектный контекст дополняет базовый профиль из Настроек.

### Протоколы

Транскрипт встречи → протокол → предпросмотр → сохранение в CRM (Safety) → опциональный черновик сообщения клиенту.

Автоматически не создаются задачи, дела и не отправляются сообщения. См. [meeting-workflow.md](./meeting-workflow.md).

## Аналитика

### Отчёты

Быстрые отчёты из Bitrix24: воронка, период, пресеты. Результат — текст/таблица с экспортом (HTML, PDF, Markdown) и опцией «открыть как документ». Запись в таймлайн Bitrix — только для отчётов по конкретной сделке/лиду и через Safety.

### Документы (Document Studio)

Деловые документы по шаблону: отчёт по воронке, сводка по сделке, КП, протокол, отчёт по задачам. Предпросмотр, экспорт, список сохранённых.

### Расписания

Плановые **read-only** сводки и алерты. В Bitrix24 ничего не меняют. Результаты попадают в Уведомления. См. [scheduled-reports.md](./scheduled-reports.md).

## Коммуникации

### Уведомления

Центр внутри приложения: результаты плановых отчётов, алерты, ошибки расписаний. Внешняя доставка (email/мессенджеры) здесь не выполняется. См. [notification-center.md](./notification-center.md).

### Исходящие

Одиночные сообщения (email и др. каналы) через Safety: черновик → подготовка → подтверждение → отправка. Полные адреса в UI маскируются. См. [safe-outbound-messaging.md](./safe-outbound-messaging.md).

### Хаб (Communications Hub)

Wazzup-каналы, диалоги, кампании и цепочки касаний. Kill switches: `COMMUNICATIONS_ENABLED` / `SEND_ENABLED` / `DRY_RUN`. См. [communications.md](./communications.md).

## Администрирование

### История

- **Операции CRM** — журнал Safety (prepare/commit/rollback), детали и откат где возможно;
- **Сформированные отчёты** — журнал быстрых отчётов и ссылки на документы.

### Пользователи

Учётные записи, роли, Bitrix user ID, data scope (`own` / `all`). Право `users.manage`. См. [user-roles.md](./user-roles.md).

### Настройки

Базовый профиль ассистента (роль, компания, методология CRM, правила ответов) и локальные предпочтения документов/сессии. Не секрет-хранилище.

### Система

Статус сервиса, метрики, журнал ошибок без секретов. Для администраторов / observability.
