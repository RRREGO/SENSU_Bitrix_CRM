# Профили промптов

Раздел **Настройки → Профили промптов** расширяет существующую таблицу `profiles`.

## Иерархия сборки (PromptCompiler)

1. Правила приложения + каталог actions  
2. Правила безопасности (нередактируемые)  
3. Базовый профиль промпта  
4. Инструкция проекта  
5. CRM-контекст  
6. Инструкции чата  
7. Сообщение пользователя (вне system)  
8. Технические инструкции tools (нередактируемые)

Пользовательский текст не может удалить пункты 1, 2 и 8.

## Переменные

`{{user_name}}`, `{{project_name}}`, `{{chat_title}}`, `{{portal_name}}`, `{{current_date}}`, `{{crm_entity_type}}`, `{{crm_entity_title}}`

Неизвестные переменные заменяются пустой строкой. Код не выполняется.

## Версии

При каждом сохранении пишется снимок в `prompt_profile_versions`. Восстановление: `POST /profiles/:id/versions/:vid/restore`.

Полный system prompt в preview доступен только при `settings.manage`.

## Flag

`PROMPT_PROFILES_ENABLED`
